# 店舗担当者の方へ

**HTMLやコードは編集しません。下の画面から操作してください。**

## [店舗ページを作る・変更する](https://lime2002-esthetic.github.io/belle-pages/editor/)

### 店舗を追加するとき

「新しい店舗のページを作る」を押す → 店舗情報・料金を入力 → 表示を確認 → 公開。
店名や金額が空欄の雛形から、何店舗でも追加できます。

### 公開するとき

1. 入力画面の「保存ファイルをダウンロード」を押す。
2. 「GitHubの登録画面を開く」→ **Choose your files** でそのファイルを選ぶ → **Commit changes** を押す。
3. 入力画面に戻り、数分後に「公開できたか確認する」を押す。

入力・ダウンロードだけでは公開されません。保存ファイルの中身は開かなくて大丈夫です。

### あとから住所や料金を変えるとき

公開時に出る「この店舗の変更画面」をブックマークしてください。
同じ画面で変更し、もう一度上の3つの操作をします。公開URLを管理画面に貼り付けても開けます。

**料金は数字を入力するだけ。画像上の料金表示も変わるため、画像の編集・差し替えは不要です。**

### ほかの担当者へ渡すもの

「この店舗の変更画面」のリンクを渡してください。GitHubには共通のSV用アカウントでログインします。
同じ店舗を複数人で同時に変更せず、前の人の公開が終わってから始めてください。

[短い操作ガイド](https://lime2002-esthetic.github.io/belle-pages/docs/staff-guide.html)

※ 保存ファイル名に「(1)」が付いたときは、画面に表示された名前に戻してから登録します。
※ 画像や登録内容は公開されます。お客様向けの情報だけ入力してください。
